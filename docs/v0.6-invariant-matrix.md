# v0.6 invariant matrix

Every invariant the v0.6 program requires, with the mechanism that enforces it and the test that would fail on a
wrong implementation. Status vocabulary:

- **COVERED** — a deterministic test exists and passes (its exact title is quoted, and a guard test checks it exists).
- **OS-COVERED** — additionally proven by a Windows real-OS integration test (a fake adapter is never evidence for HARD).
- **PLANNED** — specified, not yet implemented in a merged PR. Never claimed as shipped.

A row is only COVERED/OS-COVERED when such a test exists; a comment is never coverage. This document fills in PR by
PR; at PR A only the pure contracts are COVERED.
