# v0.5 invariant matrix

Every invariant the v0.5 program requires is listed below with:
- the mechanism that enforces it;
- the test that would fail on a plausible wrong implementation (file and exact test title);
- the deterministic black-box scenario (A–L, `test/v05-black-box-acceptance.test.ts`), where applicable;
- the live scenario (`V0_5_LIVE_L1`–`L6`, `scripts/v05-live-acceptance.mjs`), where applicable.

Status is **COVERED** only when such a test exists and passes; a comment is never coverage. The live scenarios run only
with real providers, by the maintainer, from a normal PowerShell window; they are not part of CI. The live runner is added in
part G of the delivery plan (`scripts/v05-live-acceptance.mjs`, dry-tested in `test/v05-live-verdicts.test.ts`); its real-provider
result: L1–L6 PASS on 2026-09-29. The adaptive routing policy is proven deterministically (CI, black box A); the
live L2–L6 prove the real-provider tournament integration on an explicitly authorized count (`fusion build --candidates 2`).

Test files, abbreviated: `core` = `test/v05-tournament-core.test.ts`, `exp` = `test/v05-experiments.test.ts`, `run` =
`test/v05-tournament-run.test.ts`, `bind` = `test/v05-tournament-binding.test.ts`, `build` = `test/v05-build-tournament.test.ts`,
`cal` = `test/v05-calibration.test.ts`, `sec` = `test/v05-security.test.ts`, `mesh` = `test/v05-mesh.test.ts`, `bb` =
`test/v05-black-box-acceptance.test.ts`.

## Known limitations (not invariants)

- A file under `protection.ignoredPaths` is not refused at planning time. A candidate that changes it is BLOCKED by its
  evidence (`protectedUnchanged`) and is never delivered.
- Independence is separate contexts of the configured Worker binding. Fusion never claims model diversity it did not
  configure.
- Candidate generation reuses the unchanged v0.4 engine. Each candidate therefore runs its own baseline reproduction, and
  a disagreement with the frozen baseline is treated as a non-deterministic baseline.
- A cleanup that cannot be proven complete is reported, not a delivery blocker, as in v0.4.
