## 4. What the acceptance found

- **Build attempt 1** failed closed as designed: the verification preflight refused before any model turn because Docker
  was not running. Nothing was changed; no turn was spent.
- **Create attempt 1** reached a legitimate human gate: the Lead's plan requested a decision. That exposed a product
  defect: the requested decision was dropped, so neither the build output nor `fusion show` said what to decide. Fixed in
  `7598fd9` ("fix: show and record the decision a lead requests"): the request is now a bounded, structured artifact
  (`fusion.decisionRequest` — the questions, why the role stopped, what it was unsure about; never the plan summary, a
  transcript or reasoning) recorded with the run and shown by build/create, `fusion show` and `fusion history`. The
  evidence of attempt 1 predates the fix and does not contain its question.
- `2b53ffb` ("test: clarify create live acceptance specification") replaced only the acceptance's underspecified project
  description by a complete specification (`formatDuration`, input contract, `RangeError`, format rules, nine examples,
  tests, no dependencies). `fusion create` itself is unchanged and still stops whenever a description leaves a decision open.
- **Create attempt 2** passed (section 3).

## 5. Safety facts

- The acceptance changed only the disposable targets its script created under `%TEMP%`; it mutated no other repository —
  neither this development repository nor any user project.
- Every Writer build was confirmed and every delivery approved by the human typing it; nothing was typed on the human's
  behalf. The approval, the checkout binding, the precheck and the single-use claim ran unchanged.
- The live runs ran in a normal terminal, never inside an agent session. `fusion apply` made no commit (the created
  project's only commit is the Git baseline `fusion create` writes before its build); no push, merge, tag or release was
  made during the acceptance.
- Neither the ledger nor this record holds provider replies, reasoning, transcripts or credentials.
